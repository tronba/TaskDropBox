# Contributing

Contributions must preserve the product boundaries in `TaskDropBox_Design_Document.md`, including the accountless model, offline runtime, private file authorization, independent capability keys, and live-data deletion behavior.

Submit changes with tests. Do not add cloud dependencies, telemetry, external assets, permanent identities, or features assigned to later versions without an approved design change.

Contributors may use AI-assisted development tools, but remain responsible for understanding, reviewing, testing, and licensing everything they submit. Do not provide student data, capability links, secrets, private reports, or other sensitive project data to an AI service. Material changes to the project's AI-use disclosure must also update `AI_DISCLOSURE.md`.
