# Privacy

TaskDropBox has no student or teacher accounts. A student-entered name is unverified metadata belonging to one submission.

V1 stores task content, task attachments, student-entered names, plain-text answers, submitted files and original filenames, random identifiers, and operational timestamps. It does not intentionally store email addresses, student numbers, class membership, application-level IP addresses, analytics identifiers, or telemetry.

Deleting a task removes its live database rows and files. It cannot remove exports already downloaded by teachers, external copies, older backups, or guarantee forensic erasure of physical storage blocks. Schools remain responsible for lawful use, notices, access control, backup expiry, and local education/privacy rules.
